Sistem dikembangkan dengan arsitektur frontend dan backend yang terpisah.

**Fitur utama:**

- Manajemen produk dan persediaan
- Transaksi penjualan
- Pemindaian barcode melalui kamera
- Riwayat transaksi
- Dashboard dan laporan
- REST API
- Database lokal menggunakan SQLite
